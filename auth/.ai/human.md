# 目标
实现菜单按钮审批权限后台接口

## 领域对象
- 用户角色 id
- 角色ID roleId

## 要求
- 系统基础表。如权限，用户，角色 用sys_开头
- 使用goorm
- 一个用户可能有多个角色
- 测试不是要连数据库吗，应该和权限的分开，权限相关的接口做成方法，然后测试模块可以调用，这样项目的核心代码外部可以引用，然后测试的时候使用测试模块加载测试数据库测实际代码接口，方便后续封装以及程序测试不会把无关的类蔓延到外部模块
- 权限的增删改查，批量删除 方法都要提供
- 根据用户角色id 可以查出用户所有权限，同时可以分类查出 菜单，按钮，审批，等权限
- 有接口可以一次性查出角色所有权限
- 提供多角色id 权限查询
- 可以配置默认权限 所有角色默认都有的权限
- 每个接口都有单元测试
- 使用sqlite做这个项目的测试库，方便测试
- 每个权限有对应的权限code,根据权限code和用户roleId返回是否包含该权限
